# 🎯 Jogo de Adivinhação de Números em Java

Um jogo simples de console desenvolvido em Java, onde o computador escolhe um número aleatório e o jogador tem **5 tentativas** para acertar.

---

## 📌 Sobre o Projeto

O objetivo do jogo é adivinhar um número secreto gerado aleatoriamente dentro de um intervalo pré-definido (por exemplo, entre 1 e 100). A cada palpite incorreto, o sistema fornece dicas informando se o número secreto é **maior** ou **menor** que a tentativa inserida.

### ✨ Funcionalidades
- **Geração Aleatória:** O número secreto é gerado de forma dinâmica a cada partida.
- **Contador de Tentativas:** Limite de 5 tentativas por rodada.
- **Dicas Interativas:** O jogo avisa se o seu palpite está acima ou abaixo do valor correto.
- **Tratamento de Fim de Jogo:** Mensagens personalizadas de vitória ou derrota.

---

## 🛠️ Tecnologias Utilizadas

- **Linguagem:** Java (JDK 17+ recomendado)
- **Bibliotecas:** 
  - `java.util.Scanner` (Entrada de dados do usuário)
  - `java.util.Random` (Geração do número pseudoaleatório)
